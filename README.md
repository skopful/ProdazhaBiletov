# Продажа билетов

Информационная система для продажи билетов на зрелищные и спортивные мероприятия.
Проект по специальности 09.02.07 «Информационные системы и программирование».

Выполнил: Маслов Алексей Андреевич, группа ИС1-45
Руководитель: Панасюк Анастасия Дмитриевна

## Возможности

- афиша и календарь мероприятий, поиск по типу, дате, городу, площадке и цене;
- схема зала с выбором мест, покупка и бронирование билетов;
- рабочее место кассира;
- панель администратора: мероприятия, залы, пользователи, заказы, отчёты.

## Технологии

C#, WPF, .NET Framework 4.8, MS SQL Server, ADO.NET, Visual Studio 2022.

## Запуск

Готовая программа лежит в папке `Release` (`ProdazhaBiletov.exe`).
Нужен Windows 10/11 с .NET Framework 4.8.

Для работы нужна база данных на MS SQL Server. Строка подключения находится в файле
`ProdazhaBiletov/DbHelper.cs`, пароль от базы в репозитории скрыт.
